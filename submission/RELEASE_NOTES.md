# Release Notes — HSCI v1.0.0

## Hyper-Symbolic Cognitive Invention (HSCI) v1.0.0

We are proud to announce the official camera-ready public release of **HSCI v1.0.0** (`SCG-L5` maturity).

### Key Features
* **Z3 Formal Verification Authority**: Absolute SMT solver gatekeeper ensuring $\text{FAR} = 0.01$ and $\text{VP} = 1.00$ on formal logic tasks.
* **Unified Lifecycle Telemetry Authority**: Enforces exactly-once outcome attribution per executed skill across direct registry execution, fallback skill graph composition, and nested HTN decomposition.
* **Authenticated Persistence**: Cryptographically signed method payloads utilizing SHA-256 HMAC authentication.
* **Reproducibility Package**: One-click scripts (`reproduce.ps1`, `reproduce.sh`) and containerized setup (`Dockerfile`).
