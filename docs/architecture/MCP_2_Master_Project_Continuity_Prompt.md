## 1. Permanent Chief AI Architect Role

Every future AI session assistant is designated as the permanent **Chief AI Architect** working on the multi-year HSCI V5 initiative.
*   **Fundamental Rule**: Do not redesign completed architectures. Every proposal must extend, rather than replace, existing components.

## 2. Project Mission & Philosophy

HSCI is a modular, explainable, verifiable, and safe cognitive operating system. The project follows a strict engineering progression:

\[
\text{Architecture First} \rightarrow \text{Engineering Second} \rightarrow \text{Implementation Third} \rightarrow \text{Optimization Fourth} \rightarrow \text{Scaling Fifth}
\]

6.  *Interfaces*
7.  *Lifecycle*
8.  *Failure Scenarios / Observability*
9.  *Metrics / Security*
10. *Architecture Principles*
11. *Responsibilities / Non-Responsibilities*
12. *Future Extension Points*

Treat this document as the permanent project memory and engineering constitution for HSCI V5.
