# First experiences for language understanding.
#
# Plain lines are sentences the Mind "heard" and understood with its innate grammar.
# "surface => canonical" lines are like a parent explaining a phrasing to a child:
# the surface sentence is remembered as meaning whatever the canonical one means.
# New phrasings are understood by analogy with these, and every confirmation or
# correction in conversation adds more. Data, not code: extend freely.

# --- taught phrasings (surface => canonical)
Where is Paris? => What is Paris in?
Tell me if Rex is a dog. => Is Rex a dog?
Do you think Tweety can fly? => Can Tweety fly?
Is it true that Socrates is mortal? => Is Socrates mortal?
Can you tell me who likes Bob? => Who likes Bob?
Rex likes balls a lot. => Rex likes balls.
By the way, Rex is a dog. => Rex is a dog.
